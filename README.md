# [Hlöðuvík.com](https://hloduvik.com/)

Þetta er Git hirslan (e. repository) fyrir grunninn að Hlöðuvíkursíðunni.

Þeir sem eru vel að sér í tækninni, nánar tiltekið HTML/CSS og Git, er velkomið að kvísla (e. fork) hirsluna og gera breytingar, svo dráttarbeiðni (e. pull request) inn á þessa hirslu.
